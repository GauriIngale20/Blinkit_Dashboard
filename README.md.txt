# 🛒 Blinkit Sales Analysis Dashboard | Power BI

## 📊 Project Overview

The Blinkit Sales Analysis Dashboard is an interactive business intelligence project developed using Microsoft Power BI. It helps analyze sales performance, product categories, outlet performance, and customer preferences through interactive visualizations and filters.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Understand sales distribution across item categories.
- Compare outlet performance and outlet types.
- Identify customer preferences based on item characteristics.
- Present key business insights through interactive dashboards.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Interactive Filters and Slicers

## ✨ Key Features

- Interactive dashboard with slicers and filters.
- Sales performance analysis using charts and KPIs.
- Category-wise item sales analysis.
- Outlet-wise sales comparison.
- Visual representation of business trends and patterns.

## 🚀 How to View the Project

1. Download the `Blinkit_Dashboard.pbix` file from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the downloaded `.pbix` file in Power BI Desktop.
4. Explore the report and its interactive visualizations.

**Note:** The original dataset is not included in this repository. Some report features or data refresh operations may require access to the original data source.
